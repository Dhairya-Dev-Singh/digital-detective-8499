Draft explanation to rewrite in my own words:
A compiler translates source code into another form before the program runs, often machine code. An interpreter reads and carries out instructions while the program is running. A compiled program can run quickly after translation, while an interpreter is convenient for trying code. Some language implementations combine both approaches.
