## Task 6.4 — Git command glossary

- `git init` creates a new Git repository in a folder.
- `git status` shows the current branch and whether files have changes to save.
- `git add <file>` stages a file's changes for the next commit.
- `git commit -m "message"` records the staged changes with a short description.
- `git log --oneline` shows a compact list of recent commits.
- `git branch` lists branches; `git switch -c <branch>` creates and switches to a branch.
- `git switch <branch>` switches to an existing branch.
- `git push -u origin <branch>` sends a branch to GitHub and sets its upstream.
- `git pull` gets and integrates updates from the remote branch.
