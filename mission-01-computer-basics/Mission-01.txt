Hardware items

Item       Classification   Purpose
Keyboard   Hardware         Used to enter text and commands.
Trackpad   Hardware         Used to move the pointer, click, and select items.
Display    Hardware         Shows webpages, text, and other visual output.
SSD        Hardware         Stores files and applications on the computer.

Software examples

Name       Classification   Software type             Purpose
macOS      Software         Operating system software Manages the computer's hardware and resources, and provides a platform for applications.
Brave      Software         Application software      Used to browse websites and search the web.
VS Code    Software         Application software      Used to create and edit code and text files.
Git        Software         Utility / developer tool Tracks changes to project files and manages versions.
