## 4. My understanding

Opening a website involves entering its address, having the browser request and process the webpage, and seeing the result on the screen. Browser history or cached data may be stored depending on settings; that is different from intentionally saving a file to cloud storage. Hardware is the physical equipment, while software provides instructions and tools for using the computer. Everyday systems such as ATMs, smart TVs, and traffic signals receive inputs and produce outputs for their users or surroundings.

## 5. Difficulties faced

## 6. How I resolved them
