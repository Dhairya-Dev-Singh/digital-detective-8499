Task 3.4 - Operating-system responsibilities

Responsibility       Explanation and example
Process management   The OS starts and schedules running applications. Example: it gives CPU time to the browser and other apps.
Memory management    The OS assigns RAM to running apps and reclaims it when needed. Example: open browser tabs use memory.
Device management    The OS coordinates hardware through system software. Example: it handles keyboard input and sends the page image to the display.
File management      The OS organizes files and folders and controls access to them. Example: saving this report writes a file into the mission folder.
User interface/shell The OS provides ways to interact with the computer. Example: Finder provides a graphical interface and Terminal accepts typed commands.
Security/permissions The OS controls accounts and what they may read, change, or run. Example: file permissions can allow the owner to edit a file while preventing execution.
