## 3. Commands / tools used

- `pwd` — displayed the current working directory.
- `ls`, `ls -l`, `ls -lah` — listed files and folders, including detailed and hidden-file views.
- `cd ..` — moved to the parent directory.
- `mkdir`, `touch`, `cat` — created a folder, created an empty file, and displayed file contents.
- `cp`, `mv` — copied and renamed files.
- `echo` with `>` and `>>` — wrote to a file and appended a line.
- `head` and `|` — displayed the beginning of a command's output using a pipe.
- `brew --version`, `brew list` — checked Homebrew and viewed its managed packages.

## 4. My understanding

`pwd` shows where I am working, and `ls` shows what files and folders are there. `>` replaces a file's contents if it already exists, while `>>` appends text. `cp` keeps the original and creates another copy; `mv` moves or renames a file. Flags change how a command displays information, and a pipe sends one command's output to another command. A package manager helps manage software and its packages.
