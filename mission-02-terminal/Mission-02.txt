Task 2.2 - Practise file changes safely

I added two lines to terminal-practice/notes.txt. The first line was written with >, and the second was added with >>. I used cat to confirm that both lines were present. I also copied the file to notes-backup.txt and renamed the backup to notes-backup-renamed.txt.

My answers to the reflection questions:
- > writes or replaces a file's contents; >> adds text to the end without removing the existing contents.
- cp makes another copy of a file. mv moves a file or changes its name.
- pwd tells me the path of the current working directory.
- ls shows the files and folders in the current location, which helps me see what is there.

Task 2.3 - Flags and pipes

Command used: ls -lah
- -l showed a detailed listing.
- -a included hidden files.
- -h displayed file sizes in a human-readable format.
- Compared with ls, the output included hidden entries and extra details.

Command used: ls -lah | head
The pipe (|) transferred the output of one command as input to another. In this example, ls -lah sent its output to head, which displayed the first few lines.
